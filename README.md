# 2D Space Shooter

Top-Down Shmup • Unity • C#

Game Overview

A 2D top-down space shooter where the player pilots a ship, dodges incoming enemy fire, and shoots down waves of enemies. The project focuses on projectile handling, enemy spawning, and score-driven survival.

Core Gameplay Loop

Pilot → Dodge → Shoot → Destroy Enemies → Score

Game Development
Designed a wave-based enemy spawning pattern to keep difficulty escalating.
Focused on readable player and enemy projectiles so hits feel fair.
Balanced ship movement speed against incoming bullet density.
Programming / Implementation
Built player movement and shooting controls.
Implemented enemy spawning and basic enemy movement/attack patterns.
Added projectile-collision and scoring systems.
Used C# and Unity gameplay scripting for the core shoot-and-dodge loop.
Development Challenge

How do you keep a top-down shooter readable and fair as enemy count and bullet density increase?

What I Learned

How spawning patterns, projectile speed, and scoring work together to keep a shoot-'em-up loop engaging without overwhelming the player.
